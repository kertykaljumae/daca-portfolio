## What I Did

## Key Learnings
- Learned to use basic SQL commands for data exploration (`SELECT`, `FROM`, `WHERE`, `COUNT`, `LIMIT`)
- Learned to use `DISTINCT` to find unique values
- Learned to use `AS` to create aliases for columns
- Learned to sort results using `ORDER BY`
- Learned to filter values within a specific range using `BETWEEN`
- Learned to search for specific text patterns using `LIKE`
- Learned how to identify missing (`NULL`) values in data
- Gained a better understanding of SQL query structure and filtering conditions (`AND`, `OR`)
